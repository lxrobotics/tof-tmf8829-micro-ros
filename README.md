:floppy_disc: `tof-tmf8829-micro-ros`
=====================================

Arduino sketch for interfacing a TMF8829 ToF sensor with ROS.

### How-to-compile
```bash
git clone https://github.com/lxrobotics/tof-tmf8829-micro-ros
arduino-cli compile --fqbn arduino:renesas_uno:minima tof-tmf8829-micro-ros
```
